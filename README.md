# 🤖 Simple Chatbot

A simple beginner chatbot built using Python.
This project helps beginners understand basic Python concepts like loops, conditions, and user input.

---

## 🚀 Features

* Answers simple questions
* Easy to understand code
* Beginner-friendly project
* Runs in terminal/command prompt

---

## 🛠 Technologies Used

* Python 3

---

## ▶️ Run the Project

```bash
python chatbot.py
```

---

## 📌 Example

```text
You: hi
Bot: Hello!

You: bye
Bot: Goodbye!
```
